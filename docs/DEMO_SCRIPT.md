# 5–8 minute demonstration

1. Introduce Campus Resolve and show the landing page (30 seconds).
2. Sign in as the student and submit a realistic Wi-Fi or maintenance issue (90 seconds).
3. Show that it appears on the student dashboard and has a submitted history item (45 seconds).
4. Sign in as admin, filter the queue, open the complaint, and assign it to staff (90 seconds).
5. Sign in as that staff member, show the assigned-only queue, add a note, and move the complaint through a valid next state (90 seconds).
6. Return to the student view to demonstrate the persistent chronological history (60 seconds).
7. Briefly show the architecture, role boundaries, CSRF protection, and automated test result (60 seconds).

Fallback: if MySQL is unavailable, show the packaged WAR, `TEST_REPORT.md`, the role-aware source code, and the manual verification checklist; state clearly that database workflows were not demonstrated live.
